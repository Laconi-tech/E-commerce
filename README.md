# E-commerce

Ce projet est une plateforme de e-commerce développée par un groupe de 7 personnes dans le cadre de notre formation. Il combine Symfony pour le back-end et React pour le front-end, offrant une architecture moderne et performante pour la gestion des produits, des utilisateurs, et des commandes.

Technologies utilisées :
-Back-end : Symfony (PHP framework)
-Front-end : React (JavaScript library)
-Base de données : MySQL
-API : RESTful API implémentée via Symfony

Fonctionnalités
-Gestion des produits : Consultation, création, modification, et suppression des produits via une interface admin.
-Authentification et gestion des utilisateurs : Inscription, connexion, et gestion du compte utilisateur.
-Panier et commandes : Ajout de produits au panier, gestion du panier et passage de commandes.
-Recherche et filtres : Recherche de produits avec filtres par catégorie, prix, etc.
-Dashboard administrateur : Gestion complète des produits, utilisateurs, et commandes.

# Installation
Prérequis :
-PHP version 8.1 ou supérieur
-Composer
-Node.js version 12 ou supérieure
-npm 

# Étapes

  -Cloner le dépôt
  -Installer les dépendances back-end (Symfony)
                                
    -composer install

Installer les dépendances front-end (React)

    -npm install

#Lancer l'application
Pour le back-end (Symfony) :
      
      -symfony server:start

Pour le front-end (React) :
      
      -npm start
